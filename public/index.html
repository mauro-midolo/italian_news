    Claude Code, l'opzione «non chiedere più» ha esposto password su GitHub

    La società di sicurezza Apiiro ha scoperto che, approvando un comando con «Yes, and don't ask again», Claude Code lo salva per intero, comprese eventuali credenziali, nel file .claude/settings.local.json del progetto. Il file non viene aggiunto al .gitignore del repository e in migliaia di progetti pubblici è finito online: contando anche la cronologia git e altri file di configurazione, i segreti trovati sono 2.539 in 1.994 repository. I ricercatori consigliano di controllare quei file, ruotare le credenziali e approvare schemi di comandi invece dei comandi completi.

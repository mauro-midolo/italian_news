    Piattaforme TechCrunch

    Anthropic sostituisce Git con Scion, un controllo versione pensato per gli agenti

    Anthropic racconta di aver spostato il suo monorepo da Git a Scion, un sistema interno con un server centrale che gestisce storia e merge, mentre i client tengono solo una piccola cache. Il motivo è il volume dei merge giornalieri, passati da circa 2.500 a maggio a oltre 30.000 a settembre, spinto soprattutto dagli agenti. Secondo l'azienda l'infrastruttura consuma circa 200 volte meno risorse e i checkout per la CI sono diventati molto più rapidi. Scion non viene distribuito: Anthropic ne condivide solo le idee di progetto.
